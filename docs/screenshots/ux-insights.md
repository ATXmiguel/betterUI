## Notas e boletim

**Problema:** os dados de notas sao confusos e de dificil acesso no SIGAA.
Para ver as notas de todas as disciplinas o aluno precisa entrar turma por turma,
clicar em abas diferentes, e as informacoes de cada atividade nao estao agregadas
em nenhum lugar.

**Acao atual no SIGAA:** "Emitir Boletim" — o nome e ruim porque soa como um
requerimento formal para a secretaria (como "emitir historico"). Na verdade e
so uma visualizacao de notas. O aluno nao sabe se vai gerar um PDF oficial,
acionar um processo administrativo, ou so ver os dados.

**Proposta para a extensao:**
- Renomear para algo como "Ver notas" ou "Boletim de notas" — sem o verbo "emitir".
- Quando o aluno abrir esse painel, as notas de cada atividade de cada disciplina
  ja devem estar carregadas e visiveis sem nenhum clique adicional.
- Objetivo: o que hoje exige N turmas x 2-3 cliques cada = 30+ cliques,
  deve virar 0 cliques apos a coleta inicial.
